# Deployment requirements

Run these checks before restarting the production application:

```bash
npm ci
npm run db:schema-sync
npm run db:schema-check
npm run build
npm audit --omit=dev
```

Required production environment values:

- `NEXT_PUBLIC_APP_URL=https://<canonical-lms-host>` — canonical origin used by SEB, QR verification, CSRF checks, and generated documents.
- `JWT_SECRET=<strong-random-secret>` — session and document signatures.
- `SEB_CONFIG_SALT=<strong-random-secret>` — recommended separate secret for SEB Config Keys.
- `TRUST_PROXY_HEADERS=true` — set only when the app is behind the managed Nginx proxy and Nginx overwrites `X-Forwarded-For`, `X-Forwarded-Proto`, and `X-Real-IP` from the client.
- `DB_CONNECTION_LIMIT=20` — tune below the MariaDB connection limit after accounting for the number of PM2 workers.
- `PROCTOR_RETENTION_DAYS=30` — snapshot retention from 1 to 365 days.

Safe Exam Browser policy generated by the LMS requires:

- Windows: SEB 3.10.2 or newer, Windows 10 1803+ or Windows 11.
- macOS: SEB 3.7.1 or newer, macOS 12 or newer.

After restart, verify the public HTTPS URL, application logs, one participant SEB preflight on each supported operating system, camera permission and first snapshot, autosave/reconnect, submission, manual essay grading, PDF generation, and QR verification.
